A BASE DA WEB

Três linguagens com infinitas possibilidades

Cada uma delas tem uma função específica e juntas, elas podem criar sites completos e interativos.

01 ESTRUTURA

HTML

Ele organiza o conteúdo da página, como títulos, parágrafos, imagens, links e formulários

<h1> Meu site </h1>
Aprender HTML
02 ESTILO

CSS

Ele controla o visual do site:cores, fontes, espaçamentos, animações e layouts

h1 { color: blue; }
Aprender CSS
03 INTERATIVIDADE

JavaScript

Cria um comportamento no site, deixando o site responder aos cliques, pode validar formulários e atualizar conteúdos

alert("Olá!");
Aprender JavaScript
ENTENDA NA PRÁTICA

Como as três trabalham juntas?

Imagine que você está construindo uma casa: cada parte tem uma responsabilidade.

01

HTML é a estrutura

Define os elementos que existem na página.

02

CSS é a aparência

Define como os elementos serão mostrados.

03

JavaScript é o comportamento

Faz o botão executar uma ação quando alguém clica nele.
