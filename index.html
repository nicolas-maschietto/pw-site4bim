ENTENDA NA PRÁTICA

Como as três trabalham juntas?

Imagine que você está construindo uma casa: cada tecnologia tem uma responsabilidade.

01

HTML é a estrutura

Define os elementos que existem na página, como o título e o botão.

02

CSS é a aparência

Define como o título e o botão serão apresentados visualmente.

03

JavaScript é o comportamento

Faz o botão executar uma ação quando alguém clica nele.
