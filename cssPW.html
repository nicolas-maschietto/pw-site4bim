Começar a aprender

01. O que é CSS?

CSS significa Cascading Style Sheets, ou Folhas de Estilo em Cascata. É a linguagem utilizada para definir a aparência dos elementos de uma página.

Com CSS, podemos alterar cores, fontes, bordas, espaçamentos, tamanhos, alinhamentos e animações.

HTML

Cria a estrutura e organiza o conteúdo da página.

CSS

Define a aparência e a organização visual dos elementos.

JavaScript

Adiciona interatividade e permite responder às ações do usuário.

Imagine que o HTML cria um botão e o CSS define sua cor, seu tamanho, suas bordas e seus efeitos visuais.

02. Como funciona o CSS?

Uma regra CSS possui um seletor e um conjunto de declarações. Cada declaração contém uma propriedade e um valor. 

p {
    color: green;
    font-size: 18px;
}
  • p: seleciona os parágrafos.
  • color: define a cor do texto.
  • green: é o valor da cor escolhida.
  • font-size: define o tamanho da fonte.

As chaves delimitam as declarações e o ponto e vírgula separa uma declaração da seguinte.

03. Como adicionar CSS ao HTML

CSS inline

É escrito diretamente no elemento usando o atributo style.

<p style="color: red;">
    Olá, mundo!
</p>

É útil para exemplos rápidos, mas não é ideal para estilizar um site inteiro.

CSS interno

É escrito dentro da tag style, geralmente no head.

<style>
    h1 {
        color: blue;
    }
</style>

Pode ser conveniente em páginas pequenas ou demonstrações.

CSS externo

Fica em um arquivo separado, que pode ser reutilizado em várias páginas.

<link
    rel="stylesheet"
    href="SitePWcss.css"
>

É uma boa escolha para manter o projeto organizado.

04. Seletores CSS

Os seletores indicam quais elementos receberão determinada regra de estilo. 

p {
    color: white;
}

.destaque {
    color: green;
}

#titulo-principal {
    font-size: 32px;
}
  • p: seleciona elementos pela tag.
  • .destaque: seleciona elementos pela classe.
  • #titulo-principal: seleciona um elemento pelo ID.
<h1 id="titulo-principal">
    Meu site
</h1>

<p class="destaque">
    Estou aprendendo CSS!
</p>

Uma classe pode ser utilizada em vários elementos. Já um ID deve identificar um elemento único dentro do documento.

05. Cores, fontes e tamanhos

Essas propriedades ajudam a personalizar textos e fundos. 

body {
    background-color: #101510;
    color: white;
    font-family: Arial, sans-serif;
}

h1 {
    color: #b9f66b;
    font-size: 36px;
}

p {
    font-size: 18px;
    line-height: 1.6;
}
  • color: cor do texto.
  • background-color: cor de fundo.
  • font-family: família da fonte.
  • font-size: tamanho do texto.
  • line-height: altura das linhas.

As cores podem ser representadas por nomes, como green, códigos hexadecimais, como #b9f66b, ou funções como rgb().

06. Margens, espaçamentos e bordas

Essas propriedades ajudam a organizar os elementos e a criar interfaces mais agradáveis. 

.cartao {
    margin: 20px;
    padding: 20px;
    border: 2px solid green;
    border-radius: 12px;
}
  • margin: espaço externo ao elemento.
  • padding: espaço entre o conteúdo e a borda.
  • border: borda ao redor do elemento.
  • border-radius: arredonda os cantos.
<div class="cartao">
    <h2>Meu cartão</h2>
    <p>Um exemplo de conteúdo.</p>
</div>

07. Organizando elementos com Flexbox

Flexbox é um modelo de layout que facilita o alinhamento e a distribuição de elementos em linhas ou colunas. 

.container {
    display: flex;
    justify-content: center;
    align-items: center;
    gap: 12px;
}
  • display: flex: ativa o Flexbox.
  • justify-content: alinha no eixo principal.
  • align-items: alinha no eixo transversal.
  • gap: define o espaço entre os elementos.
<div class="container">
    <div>HTML</div>
    <div>CSS</div>
    <div>JavaScript</div>
</div>

08. Criando layouts com Grid

CSS Grid ajuda a organizar elementos em linhas e colunas. É especialmente útil para grades de cartões e galerias. 

.grade {
    display: grid;
    grid-template-columns: repeat(2, 1fr);
    gap: 16px;
}

Nesse exemplo, são criadas duas colunas de tamanhos iguais. A propriedade gap define o espaço entre elas. 

<div class="grade">
    <div>Cartão 1</div>
    <div>Cartão 2</div>
    <div>Cartão 3</div>
    <div>Cartão 4</div>
</div>

09. Criando um site responsivo

Um site responsivo se adapta a diferentes tamanhos de tela, como celulares, tablets e computadores. Uma ferramenta importante para isso são as media queries. 

.grade {
    display: grid;
    grid-template-columns: repeat(2, 1fr);
    gap: 16px;
}

@media (max-width: 600px) {
    .grade {
        grid-template-columns: 1fr;
    }
}

Nesse exemplo, a grade utiliza duas colunas em telas maiores e passa para uma coluna quando a largura da tela é de 600 pixels ou menos.

Também é importante evitar larguras fixas desnecessárias e utilizar imagens que se adaptem ao espaço disponível.

10. Como praticar CSS

  1. Crie um arquivo chamado estilo.css.
  2. Conecte-o ao HTML com a tag link.
  3. Experimente alterar cores, fontes, margens e bordas.
  4. Utilize Flexbox e Grid para organizar os elementos.
  5. Teste sua página em diferentes tamanhos de tela.
