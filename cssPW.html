Aprenda a usar CSS.

O CSS serve para mudar as cores, as fontes, os tamanhos e a posição dos elementos de um site.

Começar a aprender

01. O que é CSS?

CSS significa Cascading Style Sheets, ou Folhas de Estilo em Cascata. Ele é usado para mudar a aparência de uma página HTML.

Com CSS, podemos mudar as cores, as fontes, as bordas, os espaços e a posição dos elementos.

HTML

Cria a estrutura da página.

CSS

Muda a aparência e a posição dos elementos.

JavaScript

Faz as coisas acontecerem quando o usuário interage com o site.

Por exemplo, o HTML cria um botão e o CSS permite mudar sua cor, seu tamanho e sua posição.

02. Como funciona o CSS?

No CSS, usamos seletores para escolher os elementos que queremos mudar. Depois, colocamos as propriedades e os valores que vamos usar.

Exemplo: p { color: green; font-size: 18px; }

  • p: escolhe os parágrafos.
  • color: muda a cor do texto.
  • green: é a cor escolhida.
  • font-size: muda o tamanho da letra.

As chaves guardam as regras do CSS e o ponto e vírgula separa uma regra da outra.

03. Como adicionar CSS ao HTML

CSS inline

É escrito direto na tag HTML, usando o atributo style.

Exemplo: p style="color: red;"

Serve para mudar um elemento específico.

CSS interno

É escrito dentro da tag style, no HTML.

Exemplo: style { h1 { color: blue; } }

Pode ser usado quando a página é pequena.

CSS externo

Fica em um arquivo separado do HTML.

Exemplo: link rel="stylesheet" href="SitePWcss.css"

Ajuda a organizar o código e permite usar o mesmo CSS em várias páginas.

04. Seletores CSS

Os seletores servem para escolher quais elementos vão receber as mudanças.

Exemplo: p { color: white; }

Exemplo: .destaque { color: green; }

Exemplo: #titulo-principal { font-size: 32px; }

  • p: escolhe os elementos pela tag.
  • .destaque: escolhe os elementos pela classe.
  • #titulo-principal: escolhe o elemento pelo ID.

Exemplo de HTML: h1 id="titulo-principal" Meu site /h1

A mesma classe pode ser usada em vários elementos. O ID é usado para identificar um elemento específico.

05. Cores, fontes e tamanhos

Podemos usar o CSS para mudar a cor do fundo, a cor do texto e o tamanho das letras.

Exemplo: body { background-color: #101510; color: white; font-family: Arial, sans-serif; }

Exemplo: h1 { color: #b9f66b; font-size: 36px; }

Exemplo: p { font-size: 18px; line-height: 1.6; }

  • color: muda a cor do texto.
  • background-color: muda a cor do fundo.
  • font-family: escolhe a fonte.
  • font-size: muda o tamanho da letra.
  • line-height: muda o espaço entre as linhas.

As cores podem ser escritas pelo nome, como green, por códigos como #b9f66b ou usando rgb().

06. Margens, espaços e bordas

Essas propriedades ajudam a controlar os espaços e as bordas dos elementos.

Exemplo: .cartao { margin: 20px; padding: 20px; border: 2px solid green; border-radius: 12px; }

  • margin: cria espaço fora do elemento.
  • padding: cria espaço entre o conteúdo e a borda.
  • border: adiciona uma borda.
  • border-radius: arredonda os cantos.

Exemplo de HTML: div class="cartao" Meu cartão /div

07. Organizando elementos com Flexbox

O Flexbox ajuda a alinhar os elementos e colocar um ao lado do outro ou em colunas.

Exemplo: .container { display: flex; justify-content: center; align-items: center; gap: 12px; }

  • display: flex: ativa o Flexbox.
  • justify-content: alinha os elementos no eixo principal.
  • align-items: alinha os elementos no outro eixo.
  • gap: define o espaço entre os elementos.

Podemos usar o Flexbox em uma div com outros elementos dentro, como HTML, CSS e JavaScript.

08. Criando layouts com Grid

O Grid serve para organizar elementos em linhas e colunas. Ele pode ser usado para colocar cartões lado a lado.

Exemplo: .grade { display: grid; grid-template-columns: repeat(2, 1fr); gap: 16px; }

Nesse exemplo, os elementos ficam em duas colunas do mesmo tamanho. O gap define o espaço entre eles.

Podemos usar uma div com a classe grade e colocar os cartões dentro dela.

09. Criando um site para várias telas

Um site pode ser aberto em celulares, tablets e computadores. Por isso, é importante que os elementos se ajustem ao tamanho da tela.

Para fazer isso, podemos usar media queries.

Exemplo: @media (max-width: 600px) { .grade { grid-template-columns: 1fr; } }

Nesse exemplo, a grade tem duas colunas em telas maiores. Quando a tela tem 600 pixels de largura ou menos, ela passa a ter apenas uma coluna.

Também é bom evitar larguras fixas quando não forem necessárias e deixar as imagens se ajustarem à tela.

10. Como praticar CSS

  1. Crie um arquivo chamado estilo.css.
  2. Conecte o arquivo ao HTML usando a tag link.
  3. Mude as cores, as fontes, as margens e as bordas.
  4. Use Flexbox e Grid para organizar os elementos.
  5. Abra a página no celular e no computador para testar.
