Começar a aprender

01. O que é JavaScript?

JavaScript é uma linguagem de programação muito utilizada para criar interatividade em páginas web. Com ela, um botão pode responder a um clique, um formulário pode validar informações e o conteúdo da página pode mudar sem precisar recarregá-la.

HTML

Organiza a estrutura e o conteúdo da página.

CSS

Define cores, tamanhos, espaçamentos e aparência.

JavaScript

Adiciona lógica, comportamento e interatividade.

02. Como adicionar JavaScript

Você pode escrever JavaScript dentro da tag script ou em um arquivo separado. Em projetos organizados, é comum utilizar um arquivo externo.

<script src="script.js" defer></script>

O atributo src indica o arquivo. O atributo defer faz o navegador executar o script depois de interpretar o HTML.

console.log("Olá, mundo!");

console.log() mostra uma mensagem no console do navegador, sendo útil para testar o código e investigar problemas.

03. Variáveis e tipos de dados

Variáveis guardam valores que podem ser utilizados pelo programa. Prefira const quando não precisar reatribuir o valor e use let quando ele puder mudar.

const nome = "Lucas"; let idade = 16; let estudando = true; console.log(nome); console.log(idade); console.log(estudando);

  • String: texto, como "Olá".
  • Number: número, como 10 ou 3.5.
  • Boolean: valor lógico, true ou false.
  • Array: lista de valores, como ["HTML", "CSS"].

04. Operadores

Operadores permitem fazer cálculos, comparar valores e combinar condições.

const a = 10; const b = 3; console.log(a + b); console.log(a - b); console.log(a * b); console.log(a / b); console.log(a % b); console.log(a > b); console.log(a === b);

  • +, -, * e /: operações matemáticas.
  • %: resto da divisão.
  • ===: compara valor e tipo.
  • && e ||: operadores lógicos “E” e “OU”.

05. Condições

Use if e else para executar partes diferentes do código dependendo de uma condição.

const nota = 8; if (nota >= 6) { console.log("Aprovado"); } else { console.log("Precisa estudar mais"); }

A condição dentro dos parênteses é avaliada. Se for verdadeira, o primeiro bloco é executado; caso contrário, o bloco do else é executado.

06. Repetições

Laços de repetição executam um bloco de código várias vezes. Um for é útil quando sabemos quantas repetições queremos fazer.

for (let numero = 1; numero <= 5; numero++) { console.log(numero); }

O exemplo começa em 1, continua enquanto o número for menor ou igual a 5 e aumenta o valor em 1 a cada volta.

07. Funções

Funções agrupam instruções que podem ser executadas quando necessário. Elas podem receber parâmetros e devolver resultados.

function somar(a, b) { return a + b; } const resultado = somar(4, 6); console.log(resultado);

  • Parâmetros: valores recebidos pela função, como a e b.
  • return: devolve um resultado para quem chamou a função.
  • Chamada: somar(4, 6) executa a função com esses valores.

08. Manipulando a página com DOM

O DOM permite que o JavaScript encontre e altere elementos HTML. Com getElementById(), podemos selecionar um elemento pelo seu ID.

const titulo = document.getElementById("titulo"); titulo.textContent = "Texto atualizado!";

O código procura um elemento com id="titulo" e altera seu texto. O elemento precisa existir no HTML para ser encontrado.

09. Eventos

Eventos permitem reagir às ações de quem utiliza a página, como clicar em um botão.

const botao = document.getElementById("meu-botao"); botao.addEventListener("click", function() { alert("Você clicou no botão!"); });

addEventListener() registra uma função que será executada quando o evento acontecer. Neste exemplo, a mensagem aparece após o clique.

10. Pratique: contador de cliques

Este exemplo usa variáveis, funções, seleção de elementos e eventos. Clique nos botões para testar.

Contador: 0

let contador = 0; botao.addEventListener("click", function() { contador++; valor.textContent = contador; });

Experimente explicar o que acontece quando o contador aumenta e por que o texto é atualizado.
