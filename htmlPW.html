01. O que é HTML?

HTML significa HyperText Markup Language ou Linguagem de Marcação de Hipertexto é usada para organizar e estruturar o conteúdo de páginas da internet.

Pense em um site como uma casa: o HTML representa a estrutura, o CSS cuida da aparência e o JavaScript adiciona interatividade.

01 ESTRUTURA

HTML

02 APARÊNCIA

CSS

03 INTERATIVIDADE

JavaScript

02. A estrutura básica do HTML

Todo documento HTML começa com uma estrutura que informa ao navegador como interpretar a página.

Exemplo: <!DOCTYPE html> <html lang="pt-BR"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1"> <title>Meu primeiro site</title> </head> <body> <h1>Olá, mundo!</h1> <p>Este é meu primeiro site.</p> </body> </html>

Importante: a maioria das tags possui abertura e fechamento. Por exemplo, <p> inicia um parágrafo e </p> termina esse parágrafo. Algumas tags, como <img>, não precisam de uma tag de fechamento.

Para que serve cada parte?

<!DOCTYPE> Informa que o documento utiliza HTML moderno.
<html> É o elemento principal que contém o documento HTML.
<head> Contém informações sobre a página, como título e configurações.
<title> Define o título que aparece na aba do navegador.
<body> Contém o conteúdo que aparece na página.

03. Títulos e parágrafos

Os títulos organizam as informações. O HTML possui seis níveis de título, de <h1> a <h6>. Já a tag <p> é usada para parágrafos.

Exemplo: <h1>Meu primeiro site</h1> <h2>Sobre mim</h2> <p>Olá! Estou aprendendo HTML.</p> <h2>Meus interesses</h2> <p>Gosto de tecnologia e programação.</p>

Meu primeiro site

Sobre mim

Olá,to aprendendo HTML

Meus interesses

Geralmente, utilize um <h1> para o título principal da página e organize os subtítulos com <h2> e <h3>.

04. Links e imagens

Como criar um link

A tag <a> cria um link. O atributo href indica o destino.

Exemplo: <a href="https://www.google.com"> Acessar o Google </a>

Acessar o Google

Como adicionar uma imagem

A tag <img> exibe uma imagem. O atributo src indica sua origem e alt fornece uma descrição.

Exemplo: <img src="imagem.jpg" alt="Descrição da imagem" width="250" >

O arquivo imagem.jpg precisa existir no local indicado pelo caminho de src.

05. Listas em HTML

Existem dois tipos comuns de listas: ordenadas e não ordenadas.

Lista não ordenada

Exemplo: <ul> <li>HTML</li> <li>CSS</li> <li>JavaScript</li> </ul>

  • HTML
  • CSS
  • JavaScript

Usa marcadores, como pontos, para apresentar os itens.

Lista ordenada

Exemplo: <ol> <li>Estudar HTML </li> <li>Aprender CSS</li> <li>Praticar JavaScript</li> </ol>

  1. Estudar HTML
  2. Aprender CSS
  3. Praticar JavaScript

Numera os itens automaticamente.

06. Outras tags importantes

<strong> Indica que um conteúdo possui grande importância, normalmente exibido em negrito.
<em> Dá ênfase a um trecho, normalmente exibido em itálico.
<br> Insere uma quebra de linha.
<hr> Representa uma separação temática, geralmente mostrada como uma linha horizontal.
<div> Agrupa elementos em um contêiner genérico, útil para organizar o layout.
<button> Cria um botão que pode realizar ações ou enviar formulários.

07. Como criar sua primeira página

1

Crie um arquivo

Crie um arquivo chamado index.html em seu editor de código.

2

Escreva a estrutura

Adicione as tags principais: html, head e body.

3

Adicione seu conteúdo

Crie um título, alguns parágrafos e uma lista com assuntos de que você gosta.

4

Abra no navegador

Salve o arquivo e abra-o no navegador para ver o resultado.
